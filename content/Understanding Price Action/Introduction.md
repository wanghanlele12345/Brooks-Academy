# 全书知识蓝图

## 一、书籍定位
- **类型属性**：**理论与实战混合型**（金融交易/技术分析）
- **核心议题**：基于5分钟图表的裸K（Price Action）外汇日内交易系统，重点解析价格行为背后的供需逻辑与高胜率交易形态。
- **语言风格**：**严谨务实、逻辑致密**。作者使用大量专业术语（如Double pressure, Pattern break），强调技术细节与市场心理的结合，风格冷静且极具操作性。

## 三、重构策略总结

针对本书的**实战技术指导**属性，将采取以下重构策略：

1.  **逻辑显化**：将作者隐含在大量图表描述中的**底层逻辑（如供需失衡、多空博弈）**提取出来，作为理论骨架。
2.  **形态标准化**：对于Chapter 5中的核心形态，建立**"识别条件-入场触发-止损-止盈-失效情形"**的标准化描述结构，便于记忆和执行。
3.  **图文解构**：虽然无法直接重绘图表，但会用**极高精度的文字复盘**（如"第3根K线收出长下影线，测试了1.3000整数关口..."）来还原图表信息，确保读者能脑补出画面。
4.  **术语精准化**：保留并强化核心术语（Tease break, False high等），并在首次出现时做深度定义，确保专业性。
5.  **实战场景化**：在重构复盘章节时，重点描述**决策时刻的心理博弈**，而不仅仅是事后诸葛亮的分析。
