# Brooks Academy 📈

这是一个基于 [Quartz v4](https://quartz.jzhao.xyz/) 构建的 **Al Brooks 价格行为学 (Price Action)** 学习网站。

## 项目特点

- **核心内容**: 专注于 Al Brooks 的经典价格行为分析理论。
- **LLM 优化**: 网站内容经过大语言模型 (LLM) 的深度压缩与逻辑重构，剔除冗余，保留精华，旨在提高学习效率。
- **Quartz 驱动**: 利用 Quartz 的双向链接、全文搜索和交互式图表，提供沉浸式的阅读体验。
- **结构化学习**: 从趋势反转到日内交易，涵盖了原书的核心知识点。

## 快速开始

1. **环境准备**: 确保已安装 Node.js (v18.14 或更高版本)。
2. **安装依赖**:
   ```bash
   npm install
   ```
3. **本地预览**:
   ```bash
   npx quartz build --serve
   ```
